# Release 0.6.0

## Highlights

Adds four new published packages to the monorepo — `@vanya2h/async-actions`, `@vanya2h/store`, `@vanya2h/utils-rxjs`, and `@vanya2h/utils-wagmi` — plus a `jsonSerializer` helper in `@vanya2h/utils/common` for round-tripping `bigint` and `Date` through JSON. The `integrate-configs` skill is also refreshed.

## Changes

### New Features

- **`@vanya2h/async-actions`** — new package for composable async action pipelines with status tracking. Exposes `ActionSingle`, `ActionsSet`, plus the `IAction` / `IActionSingle` / `IActionState` / `IActionStatus` / `IActionEvents` / `IActionSetEvents` types and the `InferActionInput` / `InferActionOutput` / `InferActionsResult` helpers. Built on `tiny-typed-emitter` and `immutable.List`. See `packages/async-actions/src/`.

- **`@vanya2h/utils-rxjs`** — new package of RxJS helpers:
  - `batcher` — coalesces emissions into batches.
  - `createCache` — observable-backed cache.
  - `persistBehaviorSubject` — persists a `BehaviorSubject` through a pluggable persistor (`localStorage` / stub-transport variants, `getPersistorFactory`, `getBehaviorSubjectPersistor`, `toArrayPersistor`).
  - `wrapped` status helpers: `createIdle`, `createPending`, `createFulfilled`, `createRejected`, `createWrappedPromise`.

  See `packages/utils-rxjs/src/`.

- **`@vanya2h/store`** — new reactive global store with schema-keyed caching on top of `utils-rxjs`. Exports `createGlobalStore`, `createStoreDescriptor`, `fromFetcher`, and the `IStore` / `IGlobalStore` / `IStoreFetcher` / `IStoreDescriptor` types. See `packages/store/src/globalStore/`.

- **`@vanya2h/utils-wagmi`** — new package of wagmi/viem utilities for accounts and clients: `getAccountByStatus`, `getConnectedAccount`, `getRequiredAccount`, `isContract`, `getPublicClientWithChain`, `getWalletClientWithChain`, plus chain-id inference helpers and the `WalletIsRequiredError` class. See `packages/utils-wagmi/src/`.

- **`@vanya2h/utils` — `jsonSerializer`** — new helper at `@vanya2h/utils/common` that round-trips JSON values containing `bigint` and `Date` (via tagged objects: `{ type: "bigint" | "date", value }`). Also exports the supporting types `ISerializer`, `JsonValue`, `JsonObject`, `JsonArray`, and `JsonPrimitive`. See `packages/utils/src/common/jsonSerializer.ts`.

- **`integrate-configs` skill** — rewritten for clarity and updated to detect existing ESLint/Prettier/TypeScript configs and ask before replacing them.

### Dependencies

- `@vanya2h/store` adds `immutable`, `object-hash`, `rxjs`, `zod`, and workspace deps on `@vanya2h/utils` and `@vanya2h/utils-rxjs`.
- `@vanya2h/utils-rxjs` adds `rxjs`, `immutable`, and a workspace dep on `@vanya2h/utils`.
- `@vanya2h/async-actions` adds `immutable` and `tiny-typed-emitter`.
- `@vanya2h/utils-wagmi` adds `@wagmi/core`, `viem`, and a workspace dep on `@vanya2h/utils`.
