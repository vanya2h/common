## Highlights

Introduces `@vanya2h/form-factory`, a new headless React form framework built on `react-hook-form`, Zod, and RxJS observables. `@vanya2h/eslint-config` gains a `./next` subpath for Next.js projects and a bug-fix disabling the `set-state-in-effect` rule. The `integrate-configs` skill is substantially expanded, and a new `setup-release` skill automates Changesets-based release pipeline setup.

## Changes

### New Features

- **`@vanya2h/form-factory`** (new package) — headless React form framework pairing `react-hook-form` + Zod schemas with RxJS seed observables. Core API:
  - `createFormFactory` / `createFormStubFactory` — typed factory functions that bind a Zod schema and a seed-to-defaults function.
  - `Form` — headless form root component; gates rendering on the seed observable (pending/rejected states configurable) and provides `FormProvider` context.
  - `useFormFactory` — wires a factory-built instance to `react-hook-form` with async Zod validation, submit error handling, and `CancelError` suppression.
  - `useFormSeed` — creates a stable `BehaviorSubject` for imperative seed updates.
  - `useObservableValue` — subscribes to any observable and returns `pending | fulfilled | rejected` state; synchronous emissions (e.g. `BehaviorSubject`) resolve on first render.
  - `useSubmitState` — reads `isValidating` / `isSubmitting` from the nearest `FormProvider`; exposes a convenience `disabled` flag.
  - Helper types: `IFormFactory`, `IFormInstance`, `IFormProps`, `IFormRenderProps`, `IFormFactoryBuildProps`, `IUseFormFactoryOptions`, `IUseFormFactoryResult`, `IObservableState`, `ISubmitState`, `GetFormComponentProps`, `InferFormRenderProps`, `IFormInstanceFromFactory`.
  - See `packages/form-factory/src/`.

- **`@vanya2h/eslint-config` — `./next` subpath export** — new `next.ts` config extending the `react` config with `@next/eslint-plugin-next` (recommended + core-web-vitals rules) and a built-in `.next/**` ignore glob. Import via `@vanya2h/eslint-config/next`. See `packages/eslint-config/src/next.ts`.

- **`integrate-configs` skill** — major expansion:
  - Always installs `sort-package-json` and adds a `sort-pkg` script regardless of which other configs are chosen.
  - Lint scripts (`lint` / `lint:fix`) now include `sort-package-json` checks; monorepo roots delegate via Turbo or workspace run commands.
  - Adds a `check-types` (`tsc -b --noEmit`) script for single-package and monorepo projects, with Turbo task wiring.
  - New `next` config type alongside `base`, `node`, `react`, `lib`.
  - Step 7 updates `README.md` with a scripts table when a docs section exists.
  - See `skills/integrate-configs/SKILL.md`.

- **`setup-release` skill** (new Claude Code skill) — end-to-end Changesets release pipeline setup for any JavaScript/TypeScript repo. Installs `@changesets/cli`, writes `.changeset/config.json`, adds `changeset` / `changeset:version` / `changeset:publish` scripts, and generates three GitHub Actions workflows: CI (PRs), RC releases (staging branch), and production releases (main branch). Detects package manager, Node version, Turbo, and corepack. See `skills/setup-release/SKILL.md`.

### Bug Fixes

- **`@vanya2h/eslint-config`** — `react-hooks/set-state-in-effect` is now disabled in the `react` config. The rule produced false positives in common patterns where state updates inside effects are intentional. See `packages/eslint-config/src/react.ts`.

### Dependencies

- `@vanya2h/form-factory` introduces: `react-hook-form`, `@hookform/resolvers`, `rxjs`, `zod`, `p-cancelable`.

### Internal

- Release workflows (`rc-release.yml`, `release.yml`) now run `git push --follow-tags` after publishing so npm package tags are reflected in the remote repository.
