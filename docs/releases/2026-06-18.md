## Highlights

This release introduces two new React-binding packages — `@vanya2h/utils-rxjs-react` (RxJS bindings) and `@vanya2h/store-react` (global-store hooks) — bringing the reactive stack to React consumers. It also adds an `ObservableLike` adapter to `@vanya2h/utils-rxjs` and ships an SSR fix for `useObservable`.

## Changes

### New Features

- **`@vanya2h/utils-rxjs-react` (initial release)** — React bindings for RxJS: `useObservable` (concurrent-safe `useSyncExternalStore`-based subscription), `usePending` (status state machine with `onReload`), the `<Pending>` and `<BehaviorSubjectRender>` components, `<OnlyIfTruthy>`, and a small `render` helper. Observables are late-unwrapped at the leaf to localize re-renders. See [packages/utils-rxjs-react/src/index.ts](packages/utils-rxjs-react/src/index.ts).
- **`@vanya2h/store-react` (initial release)** — React hooks for `@vanya2h/store`: `useStoreValue` (subscribes to a key, returns `IPendingStatus<T>`) and `useStoreCache` (returns the underlying `ICache<T>` for `set` / `next` / `fresh` access). See [packages/store-react/src/index.ts](packages/store-react/src/index.ts).
- **`@vanya2h/utils-rxjs`** — new `ObservableLike<T>` type and `toObservable` helper for adapting plain values into observables. See [packages/utils-rxjs/src/observableLike.ts](packages/utils-rxjs/src/observableLike.ts).

### Bug Fixes

- **`@vanya2h/utils-rxjs-react`** — fixed an SSR warning in `useObservable` by passing `getServerSnapshot` to `useSyncExternalStore`. `initialValue` is now optional; when omitted, the hook returns `T | undefined`. See [packages/utils-rxjs-react/src/useObservable.ts](packages/utils-rxjs-react/src/useObservable.ts).

### Dependencies

- **`@vanya2h/store`** — patch bump (`0.7.0` → `0.7.1`) from its `workspace:*` dependency on `@vanya2h/utils-rxjs`, which received a minor release.
